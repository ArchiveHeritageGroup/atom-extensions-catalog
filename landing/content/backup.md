## What it is for

Back up the database and the uploaded files from the administration screens, on a schedule, and restore from them when needed.

- One-off and scheduled backups, with retention so old ones are removed.
- A check that a backup file is complete, which runs again before every restore.
- Restore from the list, or from a backup file you upload; it runs in the background and shows its progress.

## Limits

A restore replaces the current database, so practise on a staging copy first. Backups are written where the backup path points: keep a copy off the server as well.
