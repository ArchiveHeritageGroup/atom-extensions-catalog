RDM Manager

Research data management with data kept in South Africa (POPIA): dataset deposit, an AI-assisted, human-approved POPIA sensitivity scan, access and embargo control, DOI minting and a compliance dashboard.

CategoryResearch services

LicenceAGPL-3.0-or-later

Sovereign (POPIA-resident) research-data-management module: dataset deposit, AI-assisted human-gated POPIA sensitivity scan, access/embargo + DOI, compliance dashboard. Reverse port of Heratio ahg-rdm (heratio#1337).

Features

  • Dataset wrapper over a container information_object
  • Per-file deposit as child IO + master digital_object (no bespoke storage)
  • POPIA sensitivity scan (deterministic + lexicon + gateway NER) [later phases]
  • Human-gated review of scan findings [later phases]
  • Access/embargo (ODRL) + DataCite DOI + public landing [later phases]
  • Compliance scoreboard + roll-up dashboard [later phases]
