Museum and GLAM (Galleries, Libraries, Archives, Museums) extension for AtoM, providing specialized functionality for cultural heritage institutions.

Requirements

  • AtoM 2.10+
  • PHP 8.1+
  • MySQL 8.0+
  • atom-framework (Laravel Query Builder)

Installation

1. Enable the plugin

php bin/atom extension:enable ahgMuseumPlugin

2. Run database migrations

php atom-framework/bin/install-plugin-schema.php --database=<database> --user=<user> --password=<password> --plugin=ahgMuseumPlugin   # from the AtoM root; never a plain mysql < install.sql

3. Clear cache

php symfony cc

4. Access the modules

  • Exhibitions: /index.php/exhibition
  • Provenance: /index.php/{object-slug}/ahgMuseumPlugin/provenance

Try it

See it on the live demo (sample data, no sign-in): museum objects in the GLAM browse.
