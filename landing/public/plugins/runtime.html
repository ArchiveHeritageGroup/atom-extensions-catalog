Generated from atom-framework by bin/build-runtime-plugin. Do not edit in place - edit the framework and regenerate. Install this before any other AHG plugin. It provides AhgController (99 plugins extend it), AhgComponents, the services, the routing loader, and a bundled Illuminate. Its install.sql creates only the runtime's own tables. Every other plugin ships its own schema.

Installation

Download the bundle and the runtime from the downloads page, then follow the bundle's INSTALL.md. In short, from the AtoM root, after a backup and on a staging copy first:

unzip ahgRuntimePlugin-<version>.zip -d plugins/
unzip ahgRuntimePlugin-<version>.zip -d plugins/
php plugins/ahgRuntimePlugin/bin/install-plugin-schema.php \
    --database=<database> --user=<user> --password=<password>

Then enable it in Admin > Plugins, clear the cache and reload PHP.
