High-performance term and taxonomy browse (subjects, places, genres) using Laravel Query Builder and direct ES queries

Features

  • Term browse via direct ES HTTP queries
  • Taxonomy browse with batch count optimization
  • Batch facet population via Laravel Query Builder
  • Theme-compatible templates (SearchHit + SimplePager)
