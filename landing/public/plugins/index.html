Grouped by what they do. Each page gives the plugin's purpose, what it depends on, and where its source and documentation are.

AI-assisted description

  • AI Condition Assessment: AI-powered condition assessment using YOLOv8 damage detection and EfficientNet classification. Companion to ahgConditionPlugin.
  • AI Tools: AI-powered tools for archival management: Named Entity Recognition (NER), Translation, Summarization, Spellcheck, and LLM Description Suggestions
  • Ask the Archive (Chatbot): Public assistant that answers questions from the published catalogue, citing the records it used. Retrieval is filtered to what the visitor may see; generation goes through the AHG AI gateway only.
  • Translation: On-prem translation integration for AtoM via local MT endpoint (supports Afrikaans/Dutch and SA languages -> English depending on MT service).

Administration

  • Backup & Restore: Database and file backup with scheduling, restore, upload and retention management
  • Email Delivery: Email deliverability: bounce capture, a suppression list, and a send-time check that holds mail to suppressed addresses.
  • Functions Docs: Auto-generated, browsable catalogue of the routes, CLI tasks and services this installation provides.
  • Help: Online help system with searchable documentation, contextual help, and FlexSearch-powered instant search
  • Landing Page Builder: Visual landing page builder with drag-and-drop blocks
  • Menu Configuration Manage: Menu configuration management - list, edit, and delete AtoM navigation menus via Laravel Query Builder
  • Reports: Central reporting dashboard with accession, authority, repository, storage and taxonomy reports
  • Settings: Extended settings management for AtoM with sections, metadata templates, and configuration tools
  • Static Page Manage: Static page management - list, edit, and delete AtoM static pages via Laravel Query Builder

Authority records

  • Authority Records Enhancement: Comprehensive authority record enhancements: external linking (Wikidata, VIAF, ULAN, LCNAF), completeness dashboard, NER-to-authority pipeline, relationship graph, merge/split workflow, bulk deduplication, structured occupations, ISDF functions, EAC-CPF export enrichment, and contact panel surfacing.
  • Authority Resolution Engine: Evidence-based authority resolution for persons, places, and organisations. Replaces name-only matching with an archivist-driven workflow that surfaces neighbourhood-context evidence, ranked candidates, and provenance-tracked decisions. Provenance writes to Fuseki as RDF-Star.

Browse and manage

  • Actor Manage: High-performance actor browse and autocomplete using Laravel Query Builder and direct ES queries. Replaces base AtoM actor browse that causes N+1 query hangs.
  • Display: GLAM browser and display modes for archival content. Includes DisplayRegistry for extension-based action/panel/badge registration.
  • Donor Manage: Donor browse and management using Laravel Query Builder
  • ISDF Function Manage: ISDF function browse, view, edit, and delete management using Laravel Query Builder
  • Repository Manage: High-performance archival institution browse using Laravel Query Builder and direct ES queries
  • Rights Holder Manage: Rights holder browse and management using Laravel Query Builder
  • Storage Manage: Physical storage browse and management using Laravel Query Builder
  • Term Taxonomy: High-performance term and taxonomy browse (subjects, places, genres) using Laravel Query Builder and direct ES queries
  • User Manage: User browse and management using Laravel Query Builder

Collection management

  • Artwork Request: Staff requests to place artworks in offices and shared spaces. Captures the request, checks availability, notifies the responsible staff and records the decision - the conversation itself stays with people.
  • Contact Management: Contact information management for actors and repositories
  • Label Generator: Label generation for archival objects with customizable templates
  • Loan Management: Shared loan management for GLAM institutions - Museums, Galleries, Archives, Libraries, and Digital Assets. Based on Collections Procedures and international GLAM standards.
  • Vendor Management: Vendor and supplier management with transactions, services, and contact tracking

Compliance

  • AI Compliance: EU AI Act Article 12 record-keeping: a tamper-evident receipt chain over every AI inference call (SHA-256 chain, RFC 8785 JCS canonical JSON, Ed25519 signatures).
  • NARSSA Transfer (South Africa): South African National Archives and Records Service Act 1996 compliance - generates NARSSA-compliant transfer manifests (METS-EAD2002 XML + digital files + manifest.csv) for records reaching disposal-due via the ahgExtendedRightsPlugin disposal workflow.
  • Privacy Compliance Management: POPIA/GDPR Privacy Compliance Management - DSAR tracking, Breach register, ROPA, Consent management
  • Redaction: Manual visual redaction of digital objects: draw regions over a PDF or image, save them, and generate a redacted copy. The original file is never modified.
  • SAHRA / NHRA Heritage Permits: South African Heritage Resources Agency (SAHRA) permit workflow under the National Heritage Resources Act, 1999 (Act 25 of 1999). Researcher applies, supervising professor endorses, then the application is submitted to SAHRA and the outcome recorded. Covers s.35 archaeology/palaeontology/meteorites, s.32 heritage object export, s.34 structures and s.36 burial grounds & graves.
  • Zimbabwe CDPA Compliance: Zimbabwe Cyber and Data Protection Act [Chapter 12:07] compliance - DPO registration, breach management, DPIA, consent tracking, data subject requests, and POTRAZ reporting
  • Zimbabwe NAZ Compliance: Zimbabwe National Archives Act [Chapter 25:06] compliance - 25-year closure rule, researcher permits, records schedules, transfers, and protected records management
  • Zimbabwe NMMZ Compliance: Zimbabwe National Museums and Monuments Act [Chapter 25:11] compliance - monument register, antiquities, export permits, archaeological sites, heritage impact assessments

Data quality

Export

  • Export: Archival export functionality for CSV, EAD, and other formats
  • GLAM Metadata Export Framework: Unified export framework supporting 10 metadata standards across GLAM sectors (Galleries, Libraries, Archives, Museums) and digital preservation.
  • Portable Export & Import: Full-system portable export and import for AtoM Heratio. Export complete instances with 15 entity types, SHA-256 checksummed manifests, and self-documenting packages. Import archives into fresh instances with ID remapping, merge/replace/dry-run modes. Also supports offline HTML viewer export for CD/USB/ZIP distribution.
  • Subtree Export: Export a record and the next N descriptions in tree order, with their digital objects, to external storage. CLI only.

Ingest and import

  • Data Migration Tool: Migrate records from external systems (ArchivesSpace, Vernon CMS, Preservica OPEX/PAX) with field mapping, Gearman background jobs, sector-specific CSV export, rights and provenance import
  • Forms Builder: Configurable metadata entry forms per repository - drag-drop form builder, template library, field assignments, draft saving, and import/export
  • FTP / SFTP Upload: Browser-based FTP/SFTP upload for CSV import digital objects. Provides drag-and-drop upload interface under Import > FTP Upload so users can place files on the server without external FTP client software. Prominently shows the path to use in CSV digitalObjectPath column.
  • Ingestion Manager: OAIS-aligned multi-stage ingestion pipeline: configure, upload, map, validate, preview, commit with rollback support
  • Watched Folder Scanner: Watched-folder streaming ingest: configurable watched folders, a scan/watch CLI that detects new files and feeds the ingest pipeline, processed/failed disposition dirs, and dedupe by SHA-256 checksum.

Integration and APIs

  • DOI Integration: DOI integration via DataCite - mint, deactivate, sync, queue processing, badge display, and verification
  • Federation: OAI-PMH Federation plugin for Heritage Platform metadata exchange
  • GraphQL: GraphQL API endpoint providing flexible querying with security safeguards including depth limiting and complexity analysis
  • Observability: Prometheus-format /metrics exporter for AtoM. Exposes app, HTTP request, DB query and queue-depth metrics through a lightweight, auth-gated (bearer token OR IP allow-list) endpoint. Auto-selecting APCu/Redis/in-memory counter storage with graceful fallback. CLI commands sample queue depth and emit node_exporter textfiles.
  • Registry: AtoM/Heratio Community Hub & Registry - Directory of institutions, vendors, software, user groups, discussions, blog, and sync API for the GLAM community.
  • ResourceSync: ResourceSync 1.1 (NISO Z39.99-2017) Source endpoints: Source Description, Capability List, Resource List and Change List as sitemap-formatted XML. Mirrors the OAI-PMH publication filter so aggregators see the same record + tombstone set across both federation surfaces.
  • REST API: Enhanced REST API v2 with API key management, full CRUD operations, batch processing, webhooks with HMAC signatures and retry logic, rate limiting, and GLAM/DAM sector support
  • SharePoint Integration: Microsoft 365 SharePoint integration: tenant config, drive registration, manual delta sync (Phase 1); webhook records handoff (Phase 2); federated search + M365 connector feed (Phase 3). One-way: SharePoint -> AtoM ingest.

Metadata
