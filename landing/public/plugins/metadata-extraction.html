Universal metadata extraction from digital objects using ExifTool, with automatic field mapping and preservation metadata support

Features

  • Automatic metadata extraction from uploaded files
  • ExifTool integration for comprehensive format support
  • Technical metadata preservation
  • Field mapping to AtoM descriptive fields
  • Batch extraction support
  • Extraction logging and audit trail
