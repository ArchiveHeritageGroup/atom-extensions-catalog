What it is for

Show digitised images, books and maps the way researchers expect: deep zoom, page turning and side-by-side comparison, from the record itself. Every digital object gets a IIIF Presentation 3 manifest, so the same images open in any IIIF viewer elsewhere.

  • Two viewers on the record page: Mirador for comparing and annotating, OpenSeadragon for fast deep zoom.
  • Share a view: zoom to a detail and copy a link that opens the same image at the same place.
  • Collections: group images from different records into a curated set with its own manifest.
  • A validation dashboard for checking manifests, and an administrators' list of shared views.

Training guide: Discovery, part 1 - IIIF images.

Known limits

Stated because a gap you know about is cheaper than one you discover:

  • rendering - the PDF or download alternative - is the last unemitted Presentation 3 property
  • Nothing checks at runtime that an image server is reachable, so a misconfigured Cantaloupe is indistinguishable from none: manifests build, viewers load, images are flat, and nothing says why
  • A conditional property that does not appear on a record and one that cannot be produced look identical from outside
  • The right-to-left branch is unexercised by any material we hold

Installation

Download the bundle and the runtime from the downloads page, then follow the bundle's INSTALL.md. In short, from the AtoM root, after a backup and on a staging copy first:

unzip ahgRuntimePlugin-<version>.zip -d plugins/
unzip ahgIiifPlugin-<version>.zip -d plugins/
php plugins/ahgIiifPlugin/bin/install-plugin-schema.php \
    --database=<database> --user=<user> --password=<password>

Then enable it in Admin > Plugins, clear the cache and reload PHP.
